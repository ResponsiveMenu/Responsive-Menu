== Installation ==

1. In your WordPress admin, go to **Plugins → Add New** and search for "Responsive Menu".
2. Click **Install Now**, then **Activate**.
3. Open **Responsive Menu** in the admin menu, pick the WordPress menu to use, and choose a theme or design your own.
4. If your theme's menu still shows on mobile, add its CSS selector under "Hide theme menu".

Manual install: upload the `responsive-menu` folder to `/wp-content/plugins/` and activate it from the **Plugins** screen.

== Frequently Asked Questions ==

= Is Responsive Menu free? =
Yes. The free plugin builds a complete mobile and hamburger menu. Responsive Menu Pro adds a desktop and mega menu, a header bar, page-by-page rules and more.

= Does it work with Elementor, Divi or other page builders? =
Yes. Responsive Menu doesn't depend on your theme or page builder. It adds its own mobile menu to the page, and you hide the original menu with a CSS selector. That's why many people use it when a theme's or builder's mobile menu won't behave.

= Does it work with block themes and WordPress 7.0? =
Yes. Responsive Menu is tested with WordPress 7.1.3, and it works on block themes as well as classic themes.

= WordPress has a Navigation block. Why use Responsive Menu? =
The Navigation block only works on block themes and in the Site Editor. Responsive Menu works on any theme or page builder, gives you 150+ design options in a live editor, lets you hide items by login state or user role, and lets you export and reuse your settings on other sites. Pro adds page-by-page rules, a mega menu and a WooCommerce cart.

= Is the menu accessible? =
Yes. The menu works with a keyboard: Tab and Shift+Tab move through it, Escape closes it, and focus stays inside the open menu. Buttons and submenus are labelled for screen readers, and the menu respects "reduce motion". It passes axe-core checks against WCAG 2.0–2.2 A/AA rules. Contrast and tap-target size depend on the colours and sizes you choose. Our [accessibility page](https://responsive.menu/features/accessible-mobile-menu/?utm_source=readme&utm_medium=plugin&utm_campaign=responsivemenu_plugin) has the full test results and a checklist.

= My theme's menu still shows on mobile. How do I hide it? =
Find the CSS selector of your theme's menu (for example `.main-navigation`) and add it under the "Hide theme menu" option. Our [guide to hiding the original menu](https://responsive.menu/knowledgebase/hiding-original-wordpress-menu/?utm_source=readme&utm_medium=plugin&utm_campaign=responsivemenu_plugin) shows how to find it.

= Can I use a different mobile menu from my desktop menu? =
Yes. Responsive Menu uses the WordPress menu you pick in its own settings, which can be different from your theme's menu.

= Can I choose which side the menu slides in from? =
Yes. The menu can open from the left, right, top or bottom, with a slide or push animation.

= Does it support translations and multilingual sites? =
The plugin is translation-ready. Pro adds WPML and Polylang support, so the menu follows the visitor's language.

= What happens if I stop renewing Pro? =
Your menu keeps working. You stop getting updates and priority support.

= Where can I get support? =
Free support is on the [WordPress.org support forum](https://wordpress.org/support/plugin/responsive-menu/). Guides are in the [knowledge base](https://responsive.menu/knowledgebase/?utm_source=readme&utm_medium=plugin&utm_campaign=responsivemenu_plugin).
